# Обновления Luma

## 🎉 Что изменено:

### 🎨 Визуальные улучшения

1. **Убран белый скроллбар** - теперь используется стильный темный скроллбар
2. **Улучшен световой эффект** - градиент плавно заходит на верхний бар
3. **Переработаны комментарии** - увеличены размеры, улучшена читаемость

### 📱 Структура приложения

1. **Отдельная вкладка "Настройки"** - теперь настройки в боковом меню и отдельной вкладке
2. **Профиль и Настройки разделены** - профиль для просмотра, настройки для редактирования

### 💬 Сообщения и чаты

1. **Поиск людей** - в разделе сообщений можно искать по нику/имени
2. **Удаление сообщений** - долгий клик (правой кнопкой) для удаления своих сообщений
3. **Отправка изображений** - можно отправлять фото в чатах
4. **Просмотр изображений** - клик на фото открывает его на весь экран
5. **Настройки чата** - кнопка меню (⋮) в чате:
   - Открыть профиль собеседника
   - Удалить чат
   - Заблокировать пользователя (в разработке)
6. **Удаление чатов** - можно полностью удалить диалог

### 💬 Комментарии

1. **Ответы на комментарии** - кнопка "Ответить" под каждым комментарием
2. **Удаление комментариев** - можно удалять свои комментарии
3. **Улучшенный дизайн** - комментарии стали крупнее и читабельнее

### 📸 Изображения

1. **Lightbox для фото** - клик на любое изображение открывает его в полноэкранном режиме
2. **Множественный выбор** - можно выбрать несколько фото (пока загружается первое)
3. **Превью в чатах** - при выборе фото показывается превью

### 👤 Профили

1. **Клик на ник/аватар** - открывает профиль пользователя
2. **Просмотр чужих профилей** - можно смотреть профили других пользователей
3. **Переход в свой профиль** - клик на своё имя/аватар

### ⚙️ Настройки

**Отдельная вкладка с разделами:**

1. **Профиль**
   - Редактирование аватара и обложки
   - Имя, никнейм, город, био

2. **Приватность**
   - Кто может писать сообщения:
     - Все пользователи
     - Только по запросу

3. **Оформление**
   - Выбор темы (Светлая/Тёмная)

4. **Выход из аккаунта**

### 🌙 Темная тема

Все новые компоненты оптимизированы для темной темы

## 📦 Обновление базы данных:

Выполните в Supabase SQL Editor:
```sql
-- Для существующих баз данных
supabase/migration_full_update.sql
```

Или для новых проектов:
```sql
supabase/schema.sql
```
